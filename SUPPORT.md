# Support

Use the repository's issue tracker for reproducible Gardenerim defects and its discussion forum for usage questions, integration help, and design proposals. Before posting, search existing issues and the package-specific README and docs.

A useful support request includes the Gardenerim package and version, framework/runtime versions, browser and operating system, a minimal reproduction, expected and actual behavior, and relevant console output. Do not include credentials, private source code, personal data, or vulnerability details.

This community project does not promise individual response times or private implementation support. Security reports follow [SECURITY.md](SECURITY.md). Questions about unsupported forks, custom themes, or application-specific architecture may need to be answered by the application's own maintainers.

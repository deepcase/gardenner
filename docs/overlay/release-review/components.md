# 浮层逐组件复核

| 组件 | 变体 | 验证重点 |
| --- | --- | --- |
| dialog | small, medium, large, xl, centered, fullscreen, top | 尺寸、长内容、模态背景、焦点、嵌套与确认 |
| drawer | small, medium, large, xl | 尺寸、长内容、模态背景、焦点、嵌套与确认 |
| popover | compact, wide | 定位、重复打开、触发方式、边界与焦点 |
| tooltip | top, bottom, start, end, start-aligned, centered, end-aligned | 定位、重复打开、触发方式、边界与焦点 |
| popconfirm | compact, wide, danger | 定位、重复打开、触发方式、边界与焦点 |
| confirm-dialog | small, medium, large, danger, centered | 尺寸、长内容、模态背景、焦点、嵌套与确认 |

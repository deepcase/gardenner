# 10 个基础入口逐项分析

| 入口 | 问题归属与发现 | 本轮修复及演示 |
| --- | --- | --- |
| Button | 组件：mini/small 横向留白偏小、默认圆角偏大，加载时隐藏文字并把图标绝对居中；窄屏会改变指定尺寸 | 对齐四档高度、内边距、图标间距、三种形状；加载图标与文字共同占位；禁用/加载保护原生点击与键盘；保留完整按钮示例 |
| ButtonGroup | 组件：实色相邻按钮负边距造成总宽不一致，端部圆角与单按钮不一致 | 对齐实色组宽度与端角；保留尺寸、形状、纵向、等分、分裂、切换参数；组禁用下传到原生按钮 |
| Card | 组件：标题字号/字重、标题区高度与正文留白不一致；网格边框写死四列 | small/medium 标题区与正文对齐；列数可通过 CSS 变量调整；移除悬停位移，保留边框、封面、操作区、网格、横排、选择及加载示例 |
| Badge | 组件及演示：计数、状态点比例偏差；99+ 仅为硬编码示例 | 对齐数字 20px、状态点 6px、字号与字重；提供动态计数、上限、零值参数；修复空徽标仍占位问题；附着、状态、Ribbon 示例保留 |
| Tag | 组件：三档高度、字重、边框与关闭按钮尺寸偏差；交互按钮 font 简写覆盖尺寸 | 对齐 20/24/32px 与 2px 圆角；加入选择/关闭共享事件、受控状态和禁用保护；演示选择、关闭、尺寸、语义色 |
| Chip | 组件：尺寸较大，带头像与关闭部件比例不协调；点击版本继承字体覆盖预设 | 与对应 Tag 高度、文字、留白一致，保留胶囊形状；头像部件适配尺寸；支持共享选择和关闭协议 |
| BadgeTagChip | 演示及 API 定位：旧兼容名称易误认为另一个完整组件 | 保留兼容入口和专门说明，演示迁移至 Badge / Tag / Chip；对照页明确它不是 Arco 独立组件 |
| Avatar | 组件：文字比例受钳制且偏小；长文字无自动缩放，图片错误未可靠回退 | 六档尺寸与默认 40px 对齐，文字 size/2；长文本按可用宽度缩放；图片失败展示调用方提供的 fallback，成功加载恢复 |
| AvatarGroup | 组件及演示：默认重叠差 0.4px，数量上限依赖外部手写 | 默认重叠 10px；提供动态 max 与 +N；上限 0 时唯一可见溢出头像保持完整宽度；保留原始成员节点 |
| DividerWithText | 组件：文字占位改变线条盒高，标题位置、间距、字重及竖线高度不一致 | 对齐 1px 横线、16px 标题留白、24px 边距与 14px 竖线；标题长文截断；修复 RTL 中心与两端定位 |

演示新增基础参数面板及 49 组真实 Arco 对照。每个基础入口继续保留自己的场景说明，参数面板提供五种框架写法。`proportions-before.json` 记录修复前测量，初始 49 组中 47 组存在差异；最终数据见 Demo 的 `docs/basic/`。

# 仪表盘逐组件复查

现有 7 个组件、39 个变体。共同修复包含原子配置校验、公开受控状态白名单、超时和取消、销毁还原、尺寸与最大高度。实际验证结果以 verification.md 及本目录日志为准。

| 组件 | 参数和变体能力 | 本轮修复 |
| --- | --- | --- |
| GKpiStat | 本地货币与精度、趋势、说明、数值开关 | 地区格式与可选趋势统一；外观配置不回退 API 数值 |
| GFilterBar | 文本、搜索、选择、日期、数字、立即提交与受控状态 | 保留草稿与输入节点；中文组合输入完成后提交；严格日历日期；默认值重置 |
| GChartContainer | 折线、面积、柱状、环形；图例、网格、坐标、数据点、数据表与 CSV | 显式图形参数生效；环形键盘选择返回合计；保留表格展开；CSV 公式前缀转义 |
| GKpiGroup | 1–4 列、容器自适应、每项格式和趋势 | 窄容器收敛到 1–2 列；单指标地区与显示选项可覆盖根配置 |
| GDashboardWidget | 内容插槽、折叠、标题与最大高度 | 配置与折叠保留内部输入；隐藏标题保留折叠操作 |
| GGoalTracker | 目标、反向预算、数值/目标/剩余显示 | 隐藏信息无多余标题块；进度保留可访问数值 |
| GGaugeChart | 半圆/圆环、范围、阈值、数值和范围显示 | 显式 arc 优先；阈值副本排序，不改变调用方数据 |

复用现有 Dashboard / DashboardGrid 组合布局，不新增功能重复的组件。CSS、Vue、React、AngularJS、Blazor 共享 CSS / controller，同时分别验证框架挂载与参数更新。
